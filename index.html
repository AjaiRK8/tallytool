Step-by-step: export ledgers from Tally and load them here

A. Export the ledgers from Tally as an XML file

  1. Open the company in Tally that this bank statement belongs to.
  2. From the Gateway of Tally, press Alt+E (Export) and select Masters. (Tally.ERP 9: Gateway of Tally → Export of Data → Masters.)
  3. On the export screen, set Format to XML (Data Interchange) and, under the masters to export, select Ledgers (or All Masters).
  4. Choose the export location and file name, then confirm the export.
  5. Tally saves an .xml file in that folder. Note where it was saved.

B. Load the file into this tool

  1. Go to the Settings page.
  2. Under Load exported ledger list (XML / CSV / XLSX), select Choose file and pick the exported XML file.
  3. The number of ledgers loaded and the company name appear below the button. The company name is filled in automatically, and the ledger and group fields can now suggest your Tally ledgers.
  4. Review the bank ledger and other ledger settings, then continue to the upload step.

Prefer Excel or CSV? In Tally, press Alt+E (Export), choose Masters, set the format to Excel or CSV, and load that file in the same way.

How to import a bank statement into Tally

This free tool converts a bank statement into a Tally XML file, so you do not have to type each entry in Tally. It works with PDF, scanned PDF, Excel, CSV and photo statements, and everything is read on your own device.

  1. Upload the statement. Use the original PDF, Excel or CSV from net banking where possible. It gives the most accurate dates, amounts and narrations.
  2. Set the company and bank ledger. Optionally load your Tally ledger list for type-ahead and checks.
  3. Review the entries. Each row is checked against the running balance of the statement. Rows that do not add up are flagged. Assign ledgers using your own rules.
  4. Create missing ledgers. The tool lists ledgers that are not yet in Tally and gives a ledger-wise summary.
  5. Export the Tally XML. In Tally, import the file through Import Data. Compare the entries with the original statement before finalising your books.

Who is it for? CA articleship trainees, small accounting practices and bookkeepers who enter bank statements into Tally often.

Frequently asked questions

How do I import a bank statement into Tally Prime? Upload the statement, set the company and bank ledger, review the entries, export the Tally XML, then in Tally use Import Data and choose the file.

Can I convert a PDF bank statement to Tally XML? Yes. Text PDFs and scanned PDFs both work, and every row is checked against the running balance.

Can I convert Excel or CSV to Tally XML? Yes. Upload the file, map the columns once, and export.

Is it free? Is my statement uploaded? It is free. Files are read in your browser and nothing is uploaded unless you choose the optional AI help.

Which banks are supported? Statements from SBI, HDFC Bank, ICICI Bank, Federal Bank, South Indian Bank, Central Bank of India, Bank of Baroda, Dhanlaxmi Bank and ESAF Small Finance Bank are read with their own layout rules. Other banks use a general reader. Always verify the result against the original statement.
